# Employee Management System (CLI)

A simple employee registration and management system via command line interface (CLI), built with Python and integrated with a MySQL database.

---

> **Important Note:** This project is strictly for **educational and learning purposes** regarding SQL database operations and credential handling in Python.
>
> **Next Steps & Optimizations:**  
> Code structure improvements, development best practices (such as using an ORM and Context Managers), new tools, and security updates (e.g., migrating to `bcrypt`) are planned for future releases.

---

## Prerequisites

Before running the project, make sure you have installed on your machine:

- **Python 3.14+**
- Running **MariaDB** server (locally)
- **pip** package manager

---

## Installation and Setup

### 1. Clone or Download the Repository

Download or clone this repository to your computer.

### 2. Install Dependencies

Install the required libraries by running:

```bash
pip install mysql-connector-python python-dotenv
